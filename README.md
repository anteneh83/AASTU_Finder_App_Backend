# AASTU Indoor Navigation System

This is the backend for the **AASTU Indoor Navigation System**, designed to help users locate and navigate rooms and blocks within the Addis Ababa Science and Technology University (AASTU) campus.


## 🔧 Features

- 📍 **Room Lookup**: Retrieve information for all rooms or a specific room by ID.
- 🔍 **Search Functionality**: Search rooms by keyword or block number.
- 🌐 **REST API**: Easily connect with frontend or mobile apps.
- 🗂️ **MongoDB Support**: All data is stored in a MongoDB database.
- 🧩 **Organized Structure**: Clean and modular codebase for easy maintenance.
