# AASTU Indoor Navigation System - Backend

This is the backend for the indoor navigation system at Addis Ababa Science and Technology University (AASTU).

## Installation

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Set up your MongoDB URI in the `.env` file.
4. Run `npm start` to start the server.

## API Routes

- `GET /api/rooms` - Get all rooms in the system.
- `GET /api/room/:id` - Get room details by room ID.
